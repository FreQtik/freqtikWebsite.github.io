# Impulse Anvil — Windows release history

## Website copy refresh — 18 November 2026 (no binary changes)

- Refocused the product page on sound design, Foley, post-production and electronic music use cases.
- Explained the evolving A/B Draw curve: movement is constructed inside one baked WAV IR, rather than being an automation lane at playback.
- Restored three historical audio examples (piano, vocal and guitar) using the existing website audio player and original MP3 files. These are general convolution examples, not a verified Draw-curve comparison.
- Simplified product-page onboarding and freeware marketing; existing downloads and v1.0.125 binary are unchanged.

## v1.0.125 — Freeware (17 November 2026)

- Windows VST3 and Standalone are free; no license key, activation, account, purchase or online validation.
- All creative features are unlocked.
- Includes **127 owner-approved factory impulse responses**.
- Retains the existing VST3 plugin identity, parameter IDs and stored project state so older projects can be opened. Back up the previous VST3 and projects before updating.
- Incorporates previously accepted WAV-load, Color C1/C2, Solo/Morph history and atomic Init Undo/Redo corrections.
- Windows Standalone includes the supplied app icon; an optional Explorer folder-icon helper is bundled with the VST3 distribution.
- **Known limitations:** A07/C05 editor-closed external Morph generation, some Omni preview Pending/READY lifecycle cases, and lack of seamless prior-IR tail continuity.
- The earlier v1.0.124 macOS testing binaries were distributed under the former license/demo model and are not part of the Windows v1.0.125 freeware build.
