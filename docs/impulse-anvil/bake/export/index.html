Bake & Export

Bake means:

Keep this IR.

Whatever prepared response you are hearing can be turned into a reusable WAV.

What Bake keeps

Bake can include:

  • A or B preparation
  • Time
  • Color and Texture
  • per-slot Normalize and Gain
  • Morph
  • A→B Lerp
  • authored routes: Draw, Path, Glue or Omni
  • Start/End slicing or reverse slicing
  • fades and Pre
  • IR In
  • EQ
  • Width
  • final IR Normalize
  • IR-side Limiter

What Bake does not keep

These controls only affect how the plugin plays on your track:

  • Input
  • Wet Level
  • Dry / Wet
  • Out

Export format

Impulse Anvil writes the result as a 32-bit floating-point WAV.

After export

The completion window shows where the file was saved.

Press Show File to reveal it directly in Explorer.

Use the result anywhere

A baked IR can be:

  • loaded back into A or B
  • combined with another Anvil Bake
  • used in another compatible convolution plugin
  • used in an IR loader that accepts standard WAV impulse responses

This is where recursive design starts:

A + B → Bake C
C + D → Bake E
E + recording → Bake F

Baking Lerp and authored routes

There is one visible Bake button. If A→B Lerp or an authored route is part of the prepared result, Bake includes it.

  • Draw writes relationship movement into the ordinary output timeline.
  • Path renders forward/backward source-time travel using its horizontal-distance clock.
  • Glue Path appends separate painted pieces and owns its duration independently of Lerp Start/Time.
  • Omni Path uses the selected Lerp source window while horizontal and vertical 2-D route travel both create output time.

Bake commits the resulting prepared construction exactly as used by the prepared Preview path.

Technical background

Bake writes the current prepared IR as 32-bit float WAV. The prepared-IR chain is bounded by a 30-second safety budget at ordinary sample rates. Final track playback mixing happens afterwards and is not embedded in the WAV.
