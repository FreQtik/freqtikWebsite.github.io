What Gets Baked?

There is one rule worth learning:

Some controls change the IR you are making. Other controls only change how you hear the plugin.

These become part of the IR

A/B → Time → Color / Texture → Slot Normalize → Slot Gain → Morph / Lerp → EDIT → IR In → EQ → Width → Normalize → Limiter → Bake

If you change something in that chain, you are changing the response that can be saved.

These are only for playback

The following controls do not become part of the baked WAV:

  • Input
  • Wet Level
  • Dry / Wet
  • Out

They only change how Anvil sounds on the track while you are working.

Simple example

If the WAV you Bake is too quiet, change IR In or the IR's Normalize/Gain path. Turning up Out only makes the plugin louder while you listen; it does not make the exported IR louder.

Technical background

Anvil prepares and caches the processed impulse response before final track playback. Dry/wet mixing and final output gain happen afterwards, so they cannot change the exported IR data.
