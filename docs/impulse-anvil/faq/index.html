FAQ

Can I use ordinary recordings as impulse responses?

Yes. Impulse Anvil can load compatible audio material and use it as convolution material. Short intentional fragments are usually easier to control than long unedited recordings.

Can I take a tiny part from the tail of an IR and export it?

Yes. Use Start and End to isolate the region. Link them when you want to scan a fixed-length window through a longer response, then press Bake.

Can I reverse only one selected region?

Yes. Move Start later than End. The region between the endpoints becomes a reversed slice.

Can I morph two IRs and save the result?

Yes. Load A and B, click Morph, choose the relationship you want, then press Bake.

Can an IR evolve from A to B inside one file?

Yes. Enable A→B Lerp. The selected Morph mode and curve define how the response develops from A toward B over time.

Are Lerp Start and Lerp Time percentages?

No. They are absolute milliseconds.

  • Lerp Start = when the transition begins
  • Lerp Time = how long it takes

Lerp Time can be 0 ms for an instant switch.

Can I draw my own Morph/Lerp curve?

Yes. Choose Draw in the Curve menu and paint the A/B movement directly.

Use U/S/N/F/R for Undo, Smooth, precision Nodes, Free endpoints and Reset.

Can Draw start or end on a blend instead of pure A/B?

Yes. Enable F in Draw.

The first and last points can then sit anywhere between A and B.

What does Path do?

Path controls both A/B blend and source-time travel.

Moving right reads later source-time. Moving left reads earlier source-time again, so a Path can create replayed or reversed sections inside the new IR.

Why can Path make the IR longer?

A straight Path reads the Lerp time span once.

Horizontal backtracking adds extra travel through that span, so the rendered IR becomes longer.

Does Path work in Bake?

Yes. Path Preview and Bake use the same prepared Path result.

What are the waveforms behind the Draw/Path graph?

They show the current A and B source shapes behind the curve editor.

Use them as visual landmarks when drawing transitions or Path routes—for example, to line up a blend change with a transient, return to an earlier event, or follow a tail by eye.

Can I load a baked IR back into Anvil?

Yes. A Bake is a standard WAV file, so it can become A or B in another design pass.

Is there a separate Bake A→B button?

No. The current interface uses one Bake button for every prepared state, including Lerp, Draw and Path.

Does Out change the exported WAV?

No. Out is final playback output only. IR In changes the prepared/baked IR level.

Does Dry/Wet change the exported WAV?

No. Dry/Wet and Wet Level affect how you hear the plugin on the track, not the IR stored by Bake.

Does 0 ms Fade still change the endpoint?

No. Fade In = 0 ms or Fade Out = 0 ms leaves that endpoint unshaped.

How far can Color Offset go?

Color Offset runs from 0–500 ms.

Tiny offsets are useful for phase/comb tone. Larger values can create clearly separated secondary events.

Does Anvil remember where I browse for IRs?

Yes. A successful manual load remembers that folder and uses it as the first choice next time.

Can I customize A, B and the other panels separately?

Yes. Open Options → Design → Customize Current Theme… and enable panel-specific colors for A, B, Morph, EQ, EDIT or OUT.

Can I export a theme?

Yes. Use Options → Design → Export Current Theme. The exported JSON can be edited, shared and imported again.

How do I switch between hearing A, B and Morph?

Click the A, B or Morph panel.

Can I make tiny millisecond adjustments more easily?

Yes. Hold Shift before dragging for fine movement or Ctrl before dragging for very fine movement.

What can Align remove?

Align can shift a source so its important peak begins earlier. If useful material existed before that peak, that pre-peak material can be lost. Compare Align on and off when the lead-in matters.

How do I reset only one part of Anvil?

Double-click Color, EQ, EDIT or OUT to reset that section.

To reset the whole control state while keeping A/B files loaded, use Options → Init / Reset Controls (keep IRs).
