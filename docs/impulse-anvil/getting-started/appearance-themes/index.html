Appearance & Themes

Impulse Anvil includes built-in themes and a theme editor.

Open:

Options → Design

Choose a built-in theme

Pick any built-in design from the Design menu.

The theme changes the interface only. It does not change the audio.

Customize the current theme

Choose:

Options → Design → Customize Current Theme…

The editor has two layers.

Global colors

Global colors create the base look for the whole plugin.

Panel-specific colors

A, B, Morph, EQ, EDIT and OUT can each override the Global colors.

Choose a panel and enable Use panel-specific colours.

That panel can then have its own:

  • panel color
  • border color
  • accent
  • highlight
  • knob color
  • text color

Leave the override off when you want that panel to inherit the Global theme.

Create a theme from an image with AI

A Theme Schema 2 file can also act as a template for AI-assisted design.

Export the current theme, give that JSON to an AI together with an image whose mood or palette you like, and ask it to generate a compatible Impulse Anvil theme from the reference.

Then paste the returned JSON into the exported file and import it back into Anvil.

Full AI theme workflow →

Save and reuse a theme

The Design menu can:

  • use saved user themes
  • import Theme JSON
  • export the current theme
  • set the current theme as default
  • reset to Anvil Blue

Export creates a complete JSON theme that can be edited or shared and then imported again.

After a successful export, Show File opens the exported file in Explorer.

Using AI to recolor a theme

Export the current theme first. Give that JSON to the AI and ask it to change only the color values while keeping the structure and required keys intact. Import the returned JSON into Anvil and inspect the result.

Technical background

Current exports use Theme Schema 2. A, B, Morph, EQ, EDIT and OUT each have an enabled flag plus panel, panelStroke, accent, highlight, knob and text colors. Disabled panel blocks inherit the Global theme. Older compatible themes remain supported.
