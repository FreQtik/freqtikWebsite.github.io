Impulse Anvil 1.0.122Hands-on learning

Learn Impulse Anvil by Doing

You don't have to study the plugin before you use it. The Basics Course teaches it one small action at a time while you have Impulse Anvil open.

Before you start: put Anvil on an instrument or audio track that is producing sound, start playback—a short loop is ideal—and keep it running while you work. You should hear each change through the track as you make it.

START WITH A SOUND

You don't need to know what an IR is

In Impulse Anvil, any WAV can become an IR.

Kick, hi-hat, shaker, clap, noise, a bad recording artifact — whatever. You can also use AIF, AIFF and FLAC.

If your DAW has a file browser, you can drag a sound straight onto A or B. You can also record your own sounds: scratch a surface, record water, room noise, a strange object, or anything else that gives you an interesting shape.

For the first few lessons, try a sound or IR around one second long. Longer or shorter works too — this just makes the changes easy to hear.

A → Shape → B → Morph → A→B Lerp → Bake again.

Full-workstation course: later lessons use Texture Depth, Color 2, Bake, the full Morph collection and A→B Lerp. Using the free demo? Start with the 5-Minute Quickstart.
What happens inside the course?

Only the current lesson stays on screen. Finish it, mark it Done, and the next one unlocks. You can always go back or open the course overview, but future lessons stay locked until you reach them.

When you finish all 34 lessons, Course Mode gives you a small local completion certificate with the date, time and your active course duration. You can save it as a PNG if you want.
