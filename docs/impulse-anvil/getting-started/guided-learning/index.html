Learn Impulse Anvil by Doing

You can read the manual in any order. This page is different: it gives you small tasks to actually perform in the plugin.

No account is required. Progress is stored only in this browser on this device. The tasks are self-checked; the website does not inspect your DAW or verify your audio.

YOUR PATH 0 / 9 quests complete
How to use this: do the task in Impulse Anvil, listen for the requested result, then mark the quest complete. The next one unlocks automatically. If you already know the plugin, press Show all quests.
QUEST 01Ready

Your first new IR

Make something before learning the vocabulary.

  1. Load a factory IR or compatible file into A.
  2. Load something obviously different into B.
  3. Click Morph and choose Time Morph.
  4. Move Morph until you hear a relationship you like.
  5. Press Bake.

Listen for: the same track changing because the response between A and B changed.

QUEST 02Locked

Cut the tail without losing the character

Learn that the useful IR can be much shorter than the original material.

  1. Use the result from Quest 01 or make another response.
  2. Open EDIT.
  3. Move End earlier until the tail becomes obviously shorter.
  4. Back it off until the character you liked returns.
  5. Bake the shorter version.

Listen for: the point where you keep the resonant identity but remove unnecessary decay.

QUEST 03Locked

Change one source before it reaches Morph

Learn the difference between preparing A/B and changing their relationship.

  1. Stay on A or B.
  2. Move Time slightly and listen.
  3. Try one small Color change.
  4. Return the controls and compare.

Listen for: A or B itself changing before Morph combines/compares the two prepared sources.

QUEST 04Locked

Ask the same sources a different question

Learn what a Morph relationship actually is.

  1. Keep A and B unchanged.
  2. Listen to Time Morph.
  3. Switch to Common or Aligned Difference.
  4. Move Morph again.

Listen for: the result changing even though neither source file changed. Only the relationship changed.

QUEST 05Locked

Paint the relationship

Turn one fixed Morph amount into movement inside the IR.

  1. Choose Time Morph.
  2. Enable A→B Lerp.
  3. Choose Draw.
  4. Paint an obvious curve from A toward B and back again.
  5. Bake it.

Listen for: the relationship changing during the response instead of staying fixed.

QUEST 06Locked

Bend source-time with Path

Learn that X can choose which part of the prepared source is read.

  1. Choose Path.
  2. Draw forward for a moment.
  3. Move backward in X through an earlier visible part of the source.
  4. Continue forward again.

Listen for: an earlier piece of the response being revisited because the route moved backward through .

QUEST 07Locked

Build a response from separate pieces

Learn why Glue Path is not just another continuous curve.

  1. Choose Glue Path.
  2. Paint one stroke over an interesting region.
  3. Paint a second separate stroke somewhere else.
  4. Preview the result.

Listen for: the separate painted pieces becoming one sequential constructed response. Glue owns its duration from the painted source-time travel instead of Lerp Start/Time.

QUEST 08Locked

Make the gesture itself create time

Hear what makes Omni Path different from ordinary Path/Glue timing.

  1. Choose Omni Path.
  2. Paint a mostly horizontal stroke.
  3. Compare it with a steep stroke that travels strongly in Y.
  4. Keep the same Lerp source window while you compare.

Listen for: vertical route travel contributing to output duration as well as horizontal travel. X still chooses source-time; Y still controls relationship depth.

FINAL QUESTLocked

Make one IR you would actually keep

Combine the ideas instead of following a recipe.

  1. Choose your own A and B material.
  2. Choose any Morph relationship for a reason.
  3. Use Draw, Path, Glue or Omni if movement helps the idea.
  4. Trim/sculpt the useful part.
  5. Bake the result and give it a name you will recognize later.

Success: you can explain what you wanted, what you changed, what you heard and why you kept the result.

    Why there is no account, streak or daily calendar
