Install & Activate

Windows VST3 installation

  1. Close your DAW.
  2. Extract the Impulse Anvil ZIP.
  3. Copy the complete Impulse Anvil.vst3 folder to C:\Program Files\Common Files\VST3\.
  4. Open your DAW and rescan VST3 plug-ins if required.

Activate the full license

  1. Open Impulse Anvil.
  2. Click Demo / Activate.
  3. Paste the license key supplied with your purchase.
  4. Click Activate.

Activation requires an internet connection. After a signed entitlement has been issued, the plugin supports offline use with periodic background validation.

Important project note

If a DAW project uses WAV files loaded from external locations, keep those files available at the same paths. A preset/session stores their paths; moving or deleting the source files can prevent exact restoration.
