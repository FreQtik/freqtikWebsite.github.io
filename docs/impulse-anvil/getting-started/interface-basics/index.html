Interface Basics

A few interaction rules make the whole plugin faster to use.

Click the panel you want to hear

A, B and Morph are also your listening navigation.

  • click A to hear A
  • click B to hear B
  • click Morph to hear the combined result

The active panel is highlighted.

A and B each have Normalize

Normalize A and Normalize B work separately.

Use them when one source arrives much quieter or louder than the other.

Gain still works with Normalize enabled, so you can normalize first and then deliberately make A or B stronger.

Fine movement

  • Shift + drag = fine
  • Ctrl + drag = very fine

This is especially useful for millisecond controls such as Start/End, Lerp timing and Color Offset.

Hold the key before you start dragging.

Hover for quick help

The main controls now include short tooltips.

Hover Time, Color, Morph, Lerp, EDIT, EQ, OUT or the playback controls for a quick explanation of what that control changes.

Random means "try another idea here"

Each Random button only changes the area it belongs to.

A / B Random beside Load

Can choose another available IR and change that slot's Time, Color and Texture.

Gain returns to 0 dB instead of being randomly boosted. Normalize stays as you set it.

A / B Random beside Color

Keeps the current file and tries a new Time/Color/Texture treatment.

Morph Random

Tries another A/B relationship.

EQ Random

Changes EQ only.

EDIT Random

Tries another slice/edit setup.

OUT Random

Creates a broader finishing variation across EDIT, EQ and Width while protecting the main playback level controls.

IR Library and manual Load

The IR Library can collect several locations in one menu:

  • bundled Factory IRs
  • Factory/User folders from older setups
  • Baked IRs
  • Expansions
  • a Custom IR Folder

When you use Load WAV…, Anvil remembers the folder you browsed and starts there next time.

Use Choose Custom IR Folder… when you keep a personal IR library somewhere else.

Double-click a title to reset that section

  • Color → reset Color/Texture
  • EQ → reset EQ
  • EDIT → reset EDIT
  • OUT → reset OUT utilities

Reset everything except the loaded files

Use:

Options → Init / Reset Controls (keep IRs)

Your A and B files stay loaded.
