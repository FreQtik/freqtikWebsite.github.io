Control Reference

Reference for Impulse Anvil 1.0.121.

Morph modes

Mode Producer description
Time Morph Direct time-domain A/B blend
Spectral Tonal/frequency fusion
Spectral BandSwap Different frequency areas can favor different sources
Spectral ZigZag More divided/artificial spectral combination
Stereo Slot Swap Left/right travel through A/B in opposite directions
Mid/Side Boundary A forms more of the center; B enters the sides

Curve choices

Curve Notes
Linear Steady A→B movement
Exp Exponential curve; K changes intensity
Log Logarithmic curve; K changes intensity
S-Curve Smooth slow-fast-slow movement
Draw Paint the A/B movement directly
Path Paint A/B movement plus forward/backward source-time travel

Draw / Path tools

Button Function
U Undo
S Smooth
N Precision nodes
F Free A/B endpoints
R Reset

Important ranges

Control Range
A/B Time 0.50×–2.00×
Color Time 0.50×–2.00×
Color Offset 0–500 ms
Texture Depth 0–4
Lerp Start 0 ms to current available IR domain
Lerp Time 0 ms to remaining available IR domain

Interaction

  • Click A, B or Morph to choose the audition state.
  • Shift + drag = fine movement.
  • Ctrl + drag = very fine movement.
  • Double-click Color, EQ, EDIT or OUT to reset that section.
  • Options → Init / Reset Controls (keep IRs) resets controls without unloading A/B.

Bake scope

Bake includes the prepared IR state, including Morph/Lerp/Draw/Path, EDIT, EQ, Width, IR In, Normalize and IR-side limiting.

Input, Wet Level, Dry/Wet and final Out are playback controls and are not embedded in the exported IR.
