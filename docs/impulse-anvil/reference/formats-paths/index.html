Formats & File Locations

Current public version

Impulse Anvil 1.0.121 — Windows 64-bit VST3

Audio files you can load

Impulse Anvil accepts:

  • .wav
  • .aif
  • .aiff
  • .flac

Use Load or drag compatible files directly onto A or B.

Factory IRs

Factory IRs ship with the plugin and appear in the IR Library as Bundled Factory.

A fresh manual Load can start from that bundled library.

Your own IR folders

The IR Library can also show:

  • User IRs
  • Baked IRs
  • Expansions
  • a Custom IR Folder
  • compatible older Factory/User locations when present

When you manually browse to an IR folder and load a file successfully, Anvil remembers that folder for the next manual Load.

Choose a custom library

Use:

IR Library → Choose Custom IR Folder…

when you keep your own IR collection somewhere else.

Baked IRs

The normal Bake destination is:

Documents\FreQtik\Impulse Anvil\Baked IRs

User data

Impulse Anvil may keep settings, presets, theme files and compatibility data under:

C:\ProgramData\FreQtik\ImpulseAnvil\

Bake format

Bake creates a 32-bit floating-point WAV.
