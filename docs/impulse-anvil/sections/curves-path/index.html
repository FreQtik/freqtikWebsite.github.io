Curves, Draw, Path & Glue

The curve system decides how the selected Morph relationship develops inside the IR. It can be a simple mathematical curve, a hand-drawn A/B movement, a route through source-time, or a sequence assembled from separate source-time pieces.

Built-in curves

  • Linear
  • Exp
  • Log
  • S-Curve

Use these when you want a predictable transition without drawing it.

Draw - paint the relationship

In Draw, left to right is the authored timeline, the bottom is A/base depth and the top is B/full target depth.

Free unlocks the endpoints, so the curve can begin or finish anywhere instead of being forced from A to B. Nodes turns the shape into editable precision points without throwing away the idea you drew.

Path - move through source-time

Path adds another dimension:

  • right = travel forward through source-time
  • left = travel backward and read earlier source material again
  • up/down = change A/B or current mode depth

A route such as forward → backward → forward really revisits earlier samples. Backtracking can make the constructed IR longer because more source-time is travelled.

Glue Path - assemble a new timeline from strokes

Glue Path is always free. Each stroke may begin and end anywhere across the full prepared source timeline and at any A/B or residual depth.

  • Horizontal distance decides how much source-time that stroke contributes.
  • Moving right reads forward; moving left reads backward.
  • Releasing the mouse ends that piece.
  • Later strokes are appended after earlier strokes in the order you created them.
  • Purely vertical travel has no meaningful time distance, so it behaves like a single-sample selection rather than creating artificial duration.

Glue owns its duration independently of Lerp Start/Time. Those timing controls step aside while Glue Path is active.

Authoring tools

  • U - local curve/path undo
  • S - smooth
  • N - precision nodes
  • F - free endpoints for Draw/Path; Glue is always free
  • R - reset

The curve display also provides small controls for waveform visibility and curve thickness so the source landmarks can stay readable while you draw.

Preview and Bake

Draw, Path and Glue feed the prepared construction used for preview and baking. When you hear a route worth keeping, Bake commits the response rather than asking you to recreate the gesture later.
