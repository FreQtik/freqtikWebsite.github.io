Curves, Draw & Path

The Curve area controls how A→B movement develops over time.

For Draw and Path, the graph reads:

B  ───────────────────────── top

        transition area

A  ───────────────────────── bottom
   start                  end

Vertical position = A/B blend.

Time normally moves from left to right.

Built-in curves

Linear

Moves from A toward B at a steady rate.

Exp

Spends more of the transition closer to one end, then changes faster later.

Use K to strengthen or soften the curve.

Log

Moves more strongly earlier, then settles toward the other end.

Use K to adjust the shape.

S-Curve

Creates a smoother slow-fast-slow transition.

Draw

Lets you paint the A/B movement directly.

Path

Lets you paint both A/B movement and source-time travel.

Draw

Choose Draw in the Curve menu.

Drag across the graph to paint the transition.

  • bottom = A
  • top = B
  • left to right = the Lerp timeline

The Draw curve is saved with plugin state, presets and DAW sessions.

Switching to another curve does not erase your Draw shape.

Draw tools

The small buttons under the graph are:

  • U — Undo the last edit
  • S — Smooth the shape
  • N — show precision nodes
  • F — Free endpoints
  • R — Reset to a straight A→B line

N — precision nodes

Enable N when you want exact control.

  • drag a node to reshape the curve
  • double-click empty curve space to add a node
  • double-click an internal node to remove it
  • Shift + drag = fine
  • Ctrl + drag = very fine

F — Free endpoints

With F off, Draw begins on A and finishes on B.

With F on, the first and last blend can sit anywhere between A and B.

Example:

normal Draw:
A → movement → B

Free Draw:
30% B → movement → 65% B

Outside the active Lerp timing window, Free Draw holds the authored start/end blend instead of forcing pure A or B.

Turning F off restores the endpoints to A and B while keeping the interior Draw shape.

Path

Path changes the meaning of the horizontal direction.

In Path mode:

  • x / left-right = which point in source-time is being read
  • y / bottom-top = A/B blend
  • the order you draw = playback order in the new IR

Forward motion

Move right:

→ → → → →

Anvil reads later source-time normally.

Backward motion

Move left during the Path:

→ → ← ← → →

The new IR goes back and reads earlier source-time again.

That creates reversed/replayed sections inside the rendered response.

Why Path can make the IR longer

A straight Path from left to right uses the normal Lerp duration.

Backtracking adds travel:

straight:
0 -------------------------- 1

backtracking:
0 --------> ----<---- ------> 1

That extra horizontal travel becomes extra output time.

The length increase comes from the route itself, not from an automatic stretch.

Path tools

The same tools remain available:

  • U — Undo
  • S — smooth the A/B vertical movement while keeping the forward/backward time route
  • N — precision Path nodes
  • F — free the A/B blend at the beginning/end
  • R — restore a straight forward A→B Path

In N mode, internal Path nodes can cross left or right past neighboring x positions. Their order stays intact, so backward-time sections remain part of the route.

Lerp Start and Lerp Time

Path operates inside the current Lerp window.

Lerp Start chooses where that window begins.

Lerp Time chooses the normal forward span available to the Path.

If the Path backtracks, the final rendered IR can become longer than Lerp Time because it travels through part of that source-time more than once.

Use the waveforms as visual landmarks

The graph shows the A and B waveforms behind the Draw/Path area.

That means the drawing surface is also a visual map of the source material.

For example, you can see a transient or tail in A and deliberately draw the Path so it:

  • reaches B around that event;
  • returns to an earlier visible section;
  • stays near A through one region;
  • crosses toward B around another recognizable shape.

This is especially useful in Path mode because you can line up forward/backward time movement with actual visible events in the IR instead of drawing blindly.

Preview and Bake

Path Preview and Bake use the same rendered Path result.

Bake exports what the prepared IR is currently doing, including the authored forward/backward route.

Technical background

Path stores an ordered 2-D route. Horizontal travel is accumulated by absolute x-distance, so leftward travel is preserved rather than sorted away. Each output position maps to source-time x and A/B blend y. A straight 0→1 route is duration-neutral; horizontal backtracking adds mapped frames. Output remains bounded by Anvil's prepared-IR safety limits.
