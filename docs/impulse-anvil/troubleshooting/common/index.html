Troubleshooting

Bake says “Nothing to export”

A prepared IR is not ready yet. Load A, or load A+B and enable Morph/A→B Lerp. If you just made a heavy change, let the preview finish rebuilding and press Bake again.

A change takes longer on a long IR

Controls that rebuild the impulse response may need to process many samples, spectral transforms and recursive Color/Texture layers. Trim the useful region earlier when possible.

My Bake level does not follow Out

That is expected. Out is playback-only. Use IR In, slot gains or IR Normalize when you want to change the exported response level.

Texture does nothing

Texture needs an enabled Color transformation. Set Texture Depth above 0 and enable C1 or C2 in that same slot.

A→B Lerp disabled the Morph knob

That is intentional. Lerp is not a single global A/B position; it changes state across the IR's own time axis. Curve, K and Lerp Time define that progression.

My external source does not restore in an old project

Impulse Anvil stores file paths for externally loaded IRs. Keep the files available at the same location or reload them manually.
