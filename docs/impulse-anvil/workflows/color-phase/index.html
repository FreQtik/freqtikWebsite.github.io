Phase & Comb Textures with Color

Color can do much more than create obvious echoes or extra layers.

When the Color copy is almost the same length and timing as the original IR, the two versions interfere with each other. Tiny movements can create large tonal changes.

This works with almost any IR.

Recipe 1 — Time-only phase color

Goal

Create a phasey, metallic or comb-like version of an IR without using Offset.

Build it

  1. Load an IR into A.
  2. Click A so you are hearing that slot.
  3. Enable C1.
  4. Keep Offset at 0 ms.
  5. Move C1 Time slightly away from 1.00.
  6. Try small differences first: around 0.99 / 1.01, then 0.95 / 1.05, then further if useful.
  7. Adjust Amount by ear.

Listen for

Do not listen for "more reverb."

Listen for the tone itself bending: hollowness, metallic peaks, notches, nasal colors, widening/narrowing impressions, or a completely different cabinet-like character.

Tip

The important thing is the difference from 1.00, not one magic value. A tiny change can be dramatic on one IR and subtle on another.

Recipe 2 — Offset-only comb color

Goal

Keep the Color copy at the same length but move it slightly later.

Build it

  1. Enable C1.
  2. Keep Time at 1.00.
  3. Move Offset slowly from about 1–20 ms.
  4. Adjust Amount.

Listen for

Very small offsets can sound like tonal filtering rather than a separate echo.

As Offset gets larger, the extra copy starts to feel more like a distinct reflection.

Recipe 3 — Mixed Time + Offset phasing

Goal

Create a less predictable interference pattern by changing both the length and position of the Color copy.

Build it

  1. Start with C1 Time only slightly different from 1.00 — for example 0.95 or 1.05.
  2. Add a tiny Offset, roughly 1–20 ms.
  3. Move Time by very small amounts.
  4. Move Offset again.
  5. Keep alternating between the two until you hit a useful pocket.

Listen for

This is where the tone can become very complex because the copy is both drifting in time and starting from a different position.

Small movements matter more than large ones.

Add C2

Once C1 gives you a useful color:

  1. enable C2;
  2. keep one Color layer subtle;
  3. let the other one use a different Time or Offset relationship.

You can create two different interference patterns inside the same IR before Texture or Morph even begins.

Add Texture carefully

Texture repeats the Color transformation in generations.

With a phasey Color setup, even Depth 1 or 2 can become very dense.

Do not assume higher Depth is better. Stop when the character becomes useful.

Bake the sweet spot

If one tiny combination sounds special, Bake it.

You can then use that phase-colored IR as new source material instead of trying to remember the exact settings.

Technical background

Color mixes a time-resampled and optionally delayed copy of the IR back with the original. When two related signals differ by small amounts in time, some frequencies reinforce while others cancel. The result is frequency-dependent comb filtering. Changing Color Time makes that relationship evolve across the IR instead of behaving like a single fixed delay.
