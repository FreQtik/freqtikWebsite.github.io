Draw Your Own A→B Movement

Draw is useful when the built-in curves are close, but the transition needs its own rhythm.

Goal

Create one IR that moves between A and B in a shape you paint yourself.

Build it

  1. Load A and B.
  2. Click Morph.
  3. Enable A→B Lerp.
  4. Choose a Morph mode.
  5. Set Lerp Start and Lerp Time.
  6. Choose Draw.
  7. Paint the curve.

The bottom of the graph is A. The top is B.

The A and B waveforms are visible behind the graph, so you can place the transition around recognizable transients, gaps and tails.

Try a return movement

Draw something like:

B        /\        /----
        /  \      /
A  ----/    \----/

The IR can move toward B, return toward A, then move back toward B later.

Make the endpoints less obvious

Enable F.

Now the IR can begin or finish on a blend instead of pure A/pure B.

For example:

  • begin around 30% B
  • move to almost pure B
  • return toward A
  • finish around 60% B

Refine with nodes

Enable N.

Add a node with a double-click, move it precisely, then use:

  • Shift for fine movement
  • Ctrl for very fine movement

Use S when a hand-drawn curve needs a smoother transition.

Listen for

Listen to when the identity changes:

  • does the attack belong to A while the body becomes B?
  • does the middle briefly return to A?
  • does the tail settle into a blend instead of pure B?

Push it further

Bake the Draw result, load it back into A, then Morph that new IR with something else.

That turns one authored movement into raw material for the next generation.
