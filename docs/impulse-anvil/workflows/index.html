Creative Workflows

This is the tips, tricks and experiments section.

The normal manual explains what every part of Anvil does. Creative Workflows answers a different question:

What can I actually make with it?

These are recipes, not rules. Start with the values shown, then move them by ear.

Create a theme from an image with AI Export Theme Schema 2, use any visual reference for mood and color, then import the generated design. Draw your own A→B movement Paint a custom transition, return toward A, and free the start/end blend. Bend time with Path Move forward, travel back through earlier source-time, then continue forward again. Phase & comb textures with Color Tiny Time and Offset differences can turn almost any IR into a new tonal filter. Turn recordings into IR material Search through metal, voice, room and field recordings for useful fragments. Recursive Baking Bake a result, load it back in, then build another generation. Multi-Morph Stereo Worlds Stack different spatial Morph ideas across generations for complex stereo fields.

The recipe format

Every workflow follows the same structure:

  • Goal — what you are trying to hear
  • Build it — the shortest useful setup
  • Listen for — what matters more than the numbers
  • Push it further — where the experiment can go next
  • Technical background — optional explanation if you want to know why it works

That makes the section useful as both a learning path and an idea library.
