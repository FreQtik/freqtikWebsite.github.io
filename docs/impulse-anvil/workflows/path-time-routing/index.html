Bend Time with Path

Path can move through the Lerp source-time in both directions.

One IR can move forward, return to earlier material, then continue forward again.

Goal

Create an IR with replayed or reversed internal time sections while the A/B blend changes at the same time.

Build it

  1. Load A and B.
  2. Enable A→B Lerp.
  3. Choose Path.
  4. Set a clear Lerp Start and Lerp Time.
  5. Draw from left toward the middle.
  6. Move back to the left.
  7. Continue toward the right edge.

Example:

START  ───────→
             ←────
                  ─────────→ END

The leftward part reads earlier source-time again.

Add A/B movement

Vertical position still controls A/B blend.

So one Path can shape both dimensions:

B          /----\
          /      \__
A  ______/          \____
   →→→→     ←←     →→→→

The IR can move toward B while going forward, return toward earlier source-time, then continue forward with a different A/B balance.

Use the waveforms as landmarks

A and B are visible behind the Path editor.

Use those waveforms like a map.

If you can see a strong event, tail or gap, you can deliberately route the Path through it, return to it, or move toward the other source at exactly that point.

This makes Path useful for designed time movement, not only abstract drawing.

Use N for precise reversals

Enable N.

Move an internal node left past another x position. The Path keeps its authored order, so that leftward section remains a backward-time route.

S keeps the route

S smooths the A/B movement without removing the forward/backward time travel.

Use it when the vertical blend feels jagged but the timing route is already good.

Reset

Press R for a straight forward A→B Path.

That removes the extra backtracking and returns to normal forward time.

Listen for

Path can create:

  • repeated internal events
  • reversed fragments inside a forward IR
  • stretched-feeling tails without simple time stretching
  • rhythmic returns to an earlier moment
  • A/B changes that happen differently on repeated source-time

Why the IR can become longer

Every backward section adds travel.

A straight route reads the Lerp window once.

A route that goes forward, backward and forward again reads part of that window more than once, so the rendered IR becomes longer.

Push it further

Bake a Path IR and use it as one side of a new Morph.

A Path-generated time structure combined later with Spectral, Stereo Slot Swap or Mid/Side Boundary can create responses whose time and stereo structures were designed in separate generations.
