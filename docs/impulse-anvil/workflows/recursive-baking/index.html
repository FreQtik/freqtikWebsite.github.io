Recursive Baking

A Bake does not have to be the final result.

It can become the next ingredient.

The basic idea

Make something:

A + B → Bake C

Then load C back into Anvil:

C + D → Bake E

Then do it again:

E + recording F → Bake G

By G, the original ingredients may no longer be obvious at all.

Build it

  1. Create a useful A/B result.
  2. Bake it.
  3. Load that Bake back into A.
  4. Put a different source in B.
  5. Change the Morph mode, Color, EDIT region or stereo treatment.
  6. Bake again.

Do not make only one lineage

Instead of:

A+B → C → D → E → F

try branches:

A+B → C1
A+B → C2

C1 + metal → D1
C2 + room  → D2

D1 + D2 → E

Branches give you more different material to recombine later.

Keep generations under control

Recursive design can quickly become dense.

When that happens:

  • use EDIT to keep only the useful section;
  • Normalize deliberately;
  • use HP/LP to remove useless buildup;
  • compare against an earlier generation;
  • stop adding layers when the new Bake is only "more" rather than better.

Strong combination

Recursive Baking becomes especially powerful with Multi-Morph Stereo Worlds, because each generation can preserve a different spatial relationship before the next Morph begins.
