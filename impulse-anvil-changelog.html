v1.0.125 — Freeware

  • All Windows features unlocked with no purchase, activation, license key, account or Internet connection.
  • 127 factory impulse-response WAVs included in the VST3 and Standalone packages.
  • Existing VST3 identity, APVTS parameter IDs and saved-project state retained.
  • Accepted Init one-step Undo/Redo, Color history, Solo/Morph history, Bake and source-loading corrections retained.
  • Windows Standalone app icon and optional VST3 Explorer folder icon helper included.
